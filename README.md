# Specly

**Сравнивай товары, а не вкладки.**

Specly — веб-инструмент для сравнения товаров по ссылкам из разных интернет-магазинов. Пользователь вставляет две ссылки, а сервис приводит характеристики к единому виду, показывает отличия и объясняет, какие параметры действительно имеют значение.

## Идея

Магазины называют одни и те же параметры по-разному:

- `Объём видеопамяти: 8192 МБ`
- `Память: 8 ГБ`
- `Video Memory Size: 8 GB`

Для Specly это один параметр: `video_memory = 8 GB`.

То же самое работает для названий характеристик, единиц измерения и значений. Цель — убрать ручную сверку десятков строк на разных сайтах.

## Что уже есть

- адаптивный интерфейс;
- ввод двух URL;
- проверка ссылок;
- таблица сравнения;
- режимы `Все`, `Только отличия`, `Важные`;
- краткий вывод по ключевым отличиям;
- демонстрационный набор RX 580 vs GTX 1060;
- архитектура фронтенда, не завязанная на конкретный магазин.

## Почему нужен backend

GitHub Pages — статический хостинг. Браузер не может надёжно загружать и разбирать страницы DNS, М.Видео и других магазинов напрямую из-за CORS, JavaScript-рендеринга, cookies и антибот-защиты.

Поэтому реальный Specly будет состоять из двух частей:

```text
Frontend (GitHub Pages)
        │
        ▼
Specly Parser API
        │
        ├── DNS adapter
        ├── M.Video adapter
        ├── Ozon adapter
        └── ...
        │
        ▼
Normalizer + Comparison Engine
```

Фронтенд уже готов к подключению API. Следующий этап — серверный парсер.

## MVP

Первая рабочая категория: **видеокарты**.

Первые магазины:

1. DNS
2. М.Видео

Базовые параметры GPU:

- модель GPU;
- объём видеопамяти;
- тип памяти;
- шина памяти;
- частоты;
- энергопотребление;
- дополнительное питание;
- размеры;
- интерфейс PCIe;
- видеовыходы;
- рекомендуемый блок питания.

## Дальше

После стабильного GPU-сравнения можно добавить:

- процессоры;
- SSD;
- ноутбуки;
- мониторы;
- смартфоны;
- дополнительные магазины;
- сравнение 3–5 товаров одновременно;
- сценарии выбора: игры, работа, энергопотребление, компактность, цена;
- историю сравнений;
- общие ссылки на готовое сравнение.

## Локальный запуск

Проект не требует сборщика:

```bash
python -m http.server 8000
```

После этого открой `http://localhost:8000`.

---

Specly не должен выбирать победителя по одной цифре. Его задача — показать реальные различия и дать пользователю понятный контекст для выбора.
